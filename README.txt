LEO Y ADRIÁN - VERSIÓN 2

Esta versión incluye escenas dibujadas dentro de la app, personajes, diálogos, avance por escenas y botón para jugar de nuevo.

Archivos para reemplazar en el repositorio:
app/src/main/AndroidManifest.xml
app/src/main/java/com/leo/adrian/MainActivity.java
app/src/main/res/layout/activity_main.xml
app/src/main/res/values/styles.xml

No necesita imágenes externas: las escenas se dibujan directamente con Canvas para que el proyecto sea fácil de compilar desde GitHub Actions.
